# CMC 无限源质

> 本文档记录 11 种无限源质的完整信息。
> 是 `Gameflow.md` 3.3 章的详细版。
> *和 ds 讨论了很长时间得到的东西*

---

## 一、通用配方

```
空无限源质 + 4x 世界物质奇点 + 2x 对应材料奇点 + 代表物
    ↓ EC 组合合成
对应材料的无限源质
```

**配方结构**: 
- **4 世界物质奇点** = "世界的基底"
- **2 材料奇点** = "目标材料的浓缩"
- **1 代表物** = "目标材料的象征"

**催化剂**: 所有 EC 奇点 (包括世界物质奇点) 的催化剂 = `advanced_ae:annihilation_singularity` (湮灭奇点) 。

---

## 二、空无限源质

**配方**: 

在 EC 9×9 终极工作台摆出 `∞` 形状: 

```
 EEE EEE
EEEEEEEEE
EE EEE EE
EEEEEEEEE
 EEE EEE
```

材料: `cmc:empty` × N

**定位**: 所有无限源质的**基础**。它是"无限的空白"——不是"某种材料的无限"。

**可能的意义**: 
- 它是**合成的原料** (合成其他源质) 
- 它是**最终的"创造"** (因为"从无到有"是创造的最高形式)

## 三、11 种无限源质

### 3.1 红石 (能量) 

| 项 | 内容 |
|---|---|
| 代表物 | `appflux:charged_redstone` ×5 |
| 用途 | **无限 RF** (Redstone Flux 的字面意思)  |
| 痛点 | 缺电 |
| 玩家需求 | 供电 |
| 章节定位 | **4 章的切入点** |

**扩展用途** (4 章) : 
```
无限红石源质
    ↓ RF = Redstone Flux
无限 RF
    ↓ 创造发电机
无限能量
    ↓ 电动马达
无限应力 = 创造通量提效
```

### 3.2 铁 (守护) 

| 项 | 内容 |
|---|---|
| 代表物 | `#minecraft:anvil` |
| 用途 | 抗性提升 / 召唤铁傀儡 |
| 痛点 | 怕死 |
| 玩家需求 | 生存 |

**设计**: 
- **抗性提升** = 被动的守护
- **召唤铁傀儡** = 主动的守护
- 对应"不想打架"和"想打架"两种玩家

**建议**: 抗性提升是**持续一段时间**，不是永久被动 (避免"无敌") 。

### 3.3 铜 (工业) 

| 项 | 内容 |
|---|---|
| 代表物 | `create:copper_casing` ×5 |
| 用途 | 无限流体设备 |
| 痛点 | 缺流体处理材料 |
| 玩家需求 | 造机器 |

**扩展用途**: 
- 无限铜 → Create 铜制流体储罐
- **辅助创造流体储罐的制作**

### 3.4 金 (食物) 

| 项 | 内容 |
|---|---|
| 代表物 | `minecraft:enchanted_golden_apple` ×2 |
| 用途 | 附魔金苹果生成 |
| 痛点 | 缺食物 / 缺强力食物 |
| 玩家需求 | 吃 |

**设计**: 
- **附魔金苹果在原版不可合成**——玩家只能从地牢找到有限的几个
- 这个配方**让它可以合成**，本身就是"打破规则"
- 给玩家一个"无脑爽"的选项

### 3.5 煤 (燃料) 

| 项 | 内容 |
|---|---|
| 代表物 | `create:blaze_burner` |
| 用途 | 无限燃料 |
| 痛点 | 缺燃料 |
| 玩家需求 | 烧 |

**扩展用途**: 
- **参与创造通量提效合成**
- **近乎无限的燃烧时间**

**注意**: 建议是"无限数量的煤"，而不是"无限的煤"——单个煤还是烧 8 个物品。

### 3.6 青金石 (经验) 

| 项 | 内容 |
|---|---|
| 代表物 | `thermal:xp_crystal` |
| 用途 | 无限经验 |
| 痛点 | 缺经验 |
| 玩家需求 | 升级 |

**设计**: 
- 经验在 CMC 里是**附魔 / 铁砧 / 修装备**的燃料
- 玩家在中后期**极其缺经验**
- **无限青金石 → 无限经验** = 再也不用刷怪塔、钓鱼

### 3.7 钻石 (万能货币) 

| 项 | 内容 |
|---|---|
| 代表物 | `scannable:rare_ores_module` |
| 用途 | 点石成金 / 钻石矿 |
| 痛点 | 缺终极材料 |
| 玩家需求 | 兑换 |

**设计**: 
- 钻石在原版是"最珍贵的基础材料"
- **"点石成金"** = 把无限钻石变成其他材料
- **"钻石矿"** = 让玩家"生成"钻石矿

**建议**: 二选一，或**服务不同场景**: 
- 点石成金 → 转换成**其他无限源质** (钻石是"万能货币") 
- 钻石矿 → 在**世界里生成钻石矿** (钻石是"世界资源") 

### 3.8 绿宝石 (交易) 

| 项 | 内容 |
|---|---|
| 代表物 | `#forge:coins` ×5 |
| 用途 | 永久村庄英雄 |
| 痛点 | 缺交易折扣 |
| 玩家需求 | 经济 |

**设计**: 
- 绿宝石在 Minecraft 里的语义是"货币"
- **永久村庄英雄** = 取消交易的随机性
- **无限绿宝石 + 永久打折 = 无限交易**

**建议**: 是"**自己所在的村庄**"打折，不是全局。

### 3.9 铅 (防护) 

| 项 | 内容 |
|---|---|
| 代表物 | **待定** |
| 用途 | 清除辐射 |
| 痛点 | 怕辐射 |
| 玩家需求 | Mek 安全 |

**设计**: 
- 铅在 Mek 里的语义是"防辐射"
- Mek 的裂变反应堆会**产生辐射**
- **清除辐射**是给 Mek 玩家的保底

**建议**: 是"持续的辐射抗性"，而不是"一次性清除"。

**待定**: 代表物是什么？ (铀？铅块？辐射防护装备？) 

### 3.10 荧石 (光照) 

| 项 | 内容 |
|---|---|
| 代表物 | **待定** |
| 用途 | 防光源方块 / 夜视 |
| 痛点 | 怕黑 |
| 玩家需求 | 照明 |

**设计**: 
- 荧石在 Minecraft 里的语义是"光"
- **防光源方块** = 建造者的需求
- **夜视** = 探索者的需求

**建议**: 是"**区域性的**" (玩家周围 16 格内没有黑暗) ，不是全局。

**待定**: 代表物是什么？ (荧石粉？蛙明灯？光灵箭？) 

### 3.11 空 (终极) 

| 项 | 内容 |
|---|---|
| 代表物 | **无** |
| 用途 | **创造本身** (从无到有)  |
| 痛点 | 无 |
| 玩家需求 | 终极 |

**设计**: 
- 在所有源质里，**`empty_infinity_source` 是唯一没有"用途"的**
- 它是**"无限的空白"**
- **"从无到有"是创造的最高形式**

**可能定位**: 
- 合成其他源质的原料
- 4 章的**终极物品**
- "创造板条箱"之上的终极

## 六、设计模式

### 6.1 每个源质对应一个"痛点"

- 红石 → 缺电
- 煤 → 缺燃料
- 铁 → 怕死
- 金 → 缺食物
- 青金石 → 缺经验
- 绿宝石 → 缺交易
- 铅 → 怕辐射
- 荧石 → 怕黑

**这些痛点横跨整个游戏**——从生存到工业，从战斗到建造。**每个玩家都能找到"自己最需要的那一个"**。

### 6.2 机制型 vs 材料型

- **机制型** (红石、煤、青金石、绿宝石) → **取消一个过程**
- **材料型** (铜、铁、金、钻石、铅) → **提供一种资源**

**两种类型对应两种玩家**: 
- 想"简化流程"的 → 机制型
- 想"获得资源"的 → 材料型

### 6.3 "空"的特殊性

`empty_infinity_source` 是唯一没有"用途"的。它的**名字就是"空"**。

**"从无到有"是创造的最高形式**。
