## 1 初步探索

### 1.1 探索世界

**开局状态**: 1 个区块，周围虚空。

**核心流程**: 

```
木头 → 圆石 + 安山岩 + 铁 + 铜
    ↓
获取世界锻造器 (初始箱子 Y = -53 ~ -60) 
    ↓
获取世界碎片 (世界锻造器，256 石头 : 1 碎片) 
    ↓ 解锁 Create 快捷方法
动力冲压机 (32 泥土 / 64 石头 : 1 碎片) 
    ↓
4x 世界碎片 → 混合搅拌 → 1x 世界段片
    ↓ 1.1 结束
```

**关键配方**: 

| 输入 | 加工 | 输出 |
|---|---|---|
| 256 石头 | 世界锻造器 | 1 世界碎片 |
| 32 泥土 / 64 石头 | 动力冲压机 | 1 世界碎片 |
| 4 世界碎片 | 混合搅拌 | 1 世界段片 |
| 2 世界碎片 + 2 安山岩 | 工作台 | 1 安山合金 |

**设计要点**: 
- **慢方法 / 快方法并存**——世界锻造器保底，动力冲压机提速
- **反捷径**——CMI 加了 Create 便捷路径，把整条链焊到 Create 上
- **粗铁处理**: 用**落锤**砸粗矿 → 5.5 粒

**落锤系统**: 
- 方块: `cmc:drop_hammer` (燧石 + 砂砾 + 圆石) 
- 落地方块: `#forge:stone`
- 可砸: 粗铁 / 粗铜 / 粗金 / 粗锌 → 对应粒

### 1.2 安山时代

**核心流程**: 

```
4x 世界段片 → 动力压缩 → 1x 世界水晶
    ↓ 分液池
100mB 世界流体 + 1x 世界碎片
    ↓
世界宝石 (4 碎片 + 4 段片 + 4 水晶 + 1000mB 世界流体) 
    ↓ 1.2 结束
```

**下界支线**: 
- 水桶丢世界流体 → 熔岩 → 黑曜石 → 下界
- **下界要塞在区块恢复前不会显露**
- 探险者指南针定位 → 搭方块到达 → 恢复区块
- 烈焰棒 → 自动化烈焰粉 → 烈焰人燃烧室
- 石英 → 石英种子 → 注液 20 次 → 高纯石英
- 序列组装 → 下界合金锻造模板

**其他内容**: 
- 鼓风机吹沙子 → 黏土 + 海带
- 落锤粉碎链: 圆石 → 砂砾 → 沙子

### 1.3 黄铜时代

**核心流程**: 

```
世界核心 + 铜 + 金 → 烈焰人加热 + 混合搅拌 → 3x 黄铜 + 1x 世界水晶
    ↓
红石粉 → 加热搅拌 → 80mB 不稳红石
    ↓ + 高纯石英
玫瑰石英 → 磨制玫瑰石英
    ↓ + 铜线 + 铁板 + 2 级锤子
电子管
    ↓
机械手 + 动力合成器
    ↓
粉碎轮
    ↓
粉碎铁锭 / 煤炭 → 铁碎块 / 煤碎块
    ↓ 2 铁碎块 + 2 煤碎块 → 加热搅拌
械金粉 (Michan)
    ↓ 械金块 + 铁块 + 2 玻璃 → 序列组装
热力机器外壳
    ↓ 1.3 结束
```

**自动化支线**: 
- 世界核心 = 世界水晶 + 压缩圆石
- 任务书目标: **自动化世界核心 ×64**

**设计要点**: 
- **黄铜配方是全局最聪明的一步**——消耗世界核心，返还世界水晶，玩家"永远差一步"
- **械金是虚构材料**——"原版钢太早出，用 Michan (Machine) 替代"
- **电子管的锤子配方**是"手工时代的告别"

## 2 工业革命

### 2.1 热力时代

**核心流程**: 

```
红石粉 + 金板 + 金棒 → 小型 RF 线圈
    ↓ + 铜板 + 锌板 + 2 级锤子
电容
    ↓
能源炉基底 (cmc:dynamo_base) 
    ↓
斯特林能源炉 (燃烧发电) 
    ↓
1 级热力机器: 磨粉机 / 流体灌装器 / 熔岩炉 / 极速冷冻机
    ↓ 熔岩炉
熔融锡 / 熔融铜 / 粘合剂 (史莱姆球) 
    ↓ 熔融锡 + 熔融铜 → 加热搅拌
熔融青铜
    ↓ + 铸模 → 极速冷冻
板 / 棍 / 锭铸模
    ↓
红石锭 / 世界物质锭
    ↓
RF 线圈
    ↓
2 级热力机器 + 树汁提取器 / 蓄水器 / 真空箱子
    ↓
多驱冲压机 (核心) 
    ↓
机器框架 / 机器升级 / 精密构件基底 → 精密构件 → 精密核心
    ↓ 2.1 结束
```

**5 种能源炉** (2.1 全解锁) : 

| 能源炉 | 燃料 | 玩家路线 |
|---|---|---|
| 斯特林 | 固体燃料 | 基础 |
| 饕餮 | 食物 | 农业 |
| 珠宝 | 宝石 | 挖矿 |
| 通货 | 硬币 | 交易 |
| 驱魔 | 经验瓶 / 附魔书 | 附魔 |

**2 级热力机器**: 
- 序列装配台 (自动工作台) 
- 离心分解机
- 结晶器
- 药水酿造机
- 锯木机
- **多驱冲压机** (最重要) 

**精密构件链**: 
```
黄铜 → 精密构件基底
    ↓ + 粘合剂 + 黄铜齿轮 + 金齿轮
精密构件
    ↓ + RF 线圈 + 4 橡胶 (待设计) 
精密核心
```

**设计要点**: 
- **电容是 1 级 → 2 级的门**——从"造电"到"存电"
- **熔岩炉 + 极速冷冻 = CMC 的"匠魂"** (功能等价、代价更小) 
- **世界物质锭的内部纹理仍是世界流体**

### 2.2 人工智能 (AE2) 

**平行章节** (可与 2.3 互换顺序) 

**核心内容**: 
- 3 级热力机器: 
  - **热解炉 (出钢！)**
  - 有机灌注器 (类似植物盆) 
  - 感应炉 (高炉 + 反应炉 + 合金炉) 
  - 部件装配机
  - 造石机
- 能源炉: 
  - **压缩能源炉** (可燃液体) 
  - **热力能源炉** (熔岩) 
- 主 mod 进度: AE2 (赛特斯水晶 / 福鲁伊克斯水晶) 

**节奏设计**: 
- AE2 的"等待" (晶体生长) → 玩家自然去做 2.3

### 2.3 更进一步 (Mek) 

**平行章节**

**核心内容**: 
- 4 级热力机器: 
  - **硝化起爆机 (矿物产出翻倍！)**
  - 流体混合机
  - 流体精炼机
  - 吸热脱水机
  - 积熔器 (产熔岩) 
- 能源炉: 
  - **霜冻能源炉 (冰发电！)**
- 主 mod 进度: Mek (钢 / 铅 / 铀) 

**节奏设计**: 
- 玩家做 2.2 的等待期 → 自然转入 2.3
- 2.3 做好后 → 接入 AE2 全自动

### 2.4 高新技术 (Advanced AE) 

**汇合章节** (2.2 + 2.3 都完成后) 

**核心内容**: 
- 5 级热力机器: 
  - **高级部件装配机** (`advanced_component_assembly`) 
  - 高级精炼器
- 主 mod 进度: 
  - Advanced AE 反应仓
  - Mek 裂变反应堆
  - 其他高级科技

**2.4 的定位**: 
- **过渡章**——准备 EC 的原料、更大的工作台
- 3.1 才是正式的 EC 章节

**EC 机器分级**: 

| 等级 | 工作台尺寸 | 阶段 |
|---|---|---|
| Basic | 3×3 | 2.4 |
| Advanced | 5×5 | 2.4 |
| Elite | 7×7 | 2.4 |
| Ultimate | 9×9 | 2.4 |

## 3 近在咫尺

### 3.1 拓展合成

**核心内容**: 
- EC 奇点系统
- **湮灭奇点**
- **世界物质奇点** (200 世界物质锭压缩) 

**关键配方**: 
```
量子压缩机 (催化剂 = 湮灭奇点) : 
200x 世界物质锭 → 1x 世界物质奇点
```

**叙事**: 
> 用技术的极致 (AE2 奇点) ，压缩世界的极致 (世界物质) 。
> 让"无"包裹"有"。让"毁灭"陪伴"创生"。

### 3.2 &kNULL

**核心流程**: 

```
世界物质奇点 + AE2 奇点 → 合金 → 不稳奇点
    ↓ 右键 cmc:chunk_spawner
error_chunk (超平坦，Y = -57 ~ -64) 
    ↓
8 层 null 方块: 
    null 草方块 ×1
    null 泥土 ×3
    null 石头 ×3
    null 基岩 ×1
    ↓ 用"特性"破坏 (状态更新) 
分解出: 原方块 + null + null_block + FTBQ 缺失物品
    ↓ null + 缺失物品 交叉摆放
cmc:empty (显示为"   "，材质空白) 
    ↓ 9 → 10 复制
更多 cmc:empty
    ↓ + null 锻造模板
null 构件
    ↓ 右键特殊方块
更快捷分离 null 系列
    ↓ 3.2 完成
```

**null 方块的破坏方式**: 

| 方块 | 操作 | 法则 |
|---|---|---|
| null 草方块 | 上方放方块 | 覆盖 |
| null 泥土 | 锄头右键 | 驯化 |
| null 石头 | 锤子砸 / 熵变机械臂冷却 | 生成 |
| null 基岩 | 活塞推动 | 物理 |

**设计要点**: 
- **null 方块"不应该存在"**——一旦状态被打破，它就"消失"
- **不是"打破方块"，是"让方块意识到自己不存在"**
- **石头有两种破坏方式** (锤子 = 基础，熵变机械臂 = 进阶，双倍产出) 

### 3.3 无限源质

**核心流程**: 

```
cmc:empty 在 EC 9×9 终极工作台摆出 ∞ 形状
    ↓
空无限源质
    ↓ + 4x 世界物质奇点 + 2x 对应材料奇点 + 代表物
对应材料的无限源质
```

**11 种无限源质**: 

| 源质 | 代表物 | 用途 |
|---|---|---|
| 红石 | `appflux:charged_redstone` ×5 | 无限 RF |
| 铁 | `#minecraft:anvil` | 抗性提升 / 召唤铁傀儡 |
| 铜 | `create:copper_casing` ×5 | 无限流体设备 |
| 金 | `minecraft:enchanted_golden_apple` ×2 | 附魔金苹果生成 |
| 煤 | `create:blaze_burner` | 无限燃料 |
| 青金石 | `thermal:xp_crystal` | 无限经验 |
| 钻石 | `scannable:rare_ores_module` | 点石成金 / 钻石矿 |
| 绿宝石 | `#forge:coins` ×5 | 永久村庄英雄 |
| 铅 | 待定 | 清除辐射 |
| 荧石 | 待定 | 防光源方块 / 夜视 |
| 空 | 无 | 创造本身 |

**未来可能加入**: 铀 (辐射) 、镍 (？) 、颜色 (染色) 。

## 4 创造模式

### 4.1 还差一点

**切入点: 无限红石源质**

```
无限红石源质
    ↓ RF = Redstone Flux 的字面意思
无限 RF
    ↓ 创造发电机
无限能量
    ↓ 电动马达 (RF → 应力) 
无限应力 = 无限效率 = 创造通量提效
    ↓
山寨创造物品
    ↓
无限化学品 + 无限流体
    ↓
无限物品
```

**创造物品序列**: 

| 顺序 | 物品 | 取消的限制 |
|---|---|---|
| 1 | 创造马达 | Create 应力 + 转速 |
| 2 | 创造发电机 | 能量 |
| 3 | 创造通量线圈 | RF 消耗 |
| 4 | 创造通量提效 | 速度限制 |
| 5 | 创造流休储罐 | 流体 |
| 6 | 创造化学品储罐 / 创造流体储罐 | 化学品 / 流体 |
| 7 | 创造版条箱 | 存储 |
| 8 | 创造板条箱 | 存储 |

**穿插**: 创造 ME 组件系列物品 (`creative_cell` / `imperfect_creative_cell`) 

**山寨创造物品**: 
- `cmc:creative_fiuld_tank` (拼写待定) 
- `cmc:creative_create`

**设计要点**: 
- **"无限红石源质 = 无限 RF"是玩家自己发现的瞬间**
- **山寨物品是"预告片"**——让玩家先尝到创造的甜头
- **每项创造物品取消一个限制**

## 通用章节
