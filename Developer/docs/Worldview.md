## 一、核心设定

### 1.1 世界为什么只剩一个区块

世界没有消失。它被**拆开**了。

拆成无数细小的碎片，每一片都停留在自己的角落里，还记着自己原本的样子: 森林、沙漠、雪原、深海。

**技术特点**: 每个群系 / 地形被拆成**独立维度** (例如 `minecraft:overworld_badland_gen` 是只有恶地群系的维度) 。区块生成器的本质是**从这些维度里提取一个区块，复制回主世界**。

**玩家的感受**: 世界不是"荒芜"的，是"不在这里"的。碎片还在，只是散落在别处。

### 1.2 玩家的使命

**恢复世界**。这是 CMC 的玩法核心，不属于任何线性章节，放在通用 (`*.2`) 里。

玩家通过**区块生成器**，把碎片一块块放回来。可以选择恢复什么群系，选择权在玩家手里。

## 二、世界的形态

### 2.1 伊始之地

玩家出生时，世界只剩**一块 16×16 的区域**，边缘之外是虚空。

在初始区块的最底部 (Y = -53 ~ -60) 有一个箱子，里面是**世界锻造器**——恢复世界的起点。

### 2.2 世界恢复链
```
世界碎片 (worldfragment)
↓ 4x 混合搅拌
世界段片 (worldshard)
↓ 4x 动力压缩
世界水晶 (worldcrystal)
↓ 分液池
100mB 世界流体 (world_fluid) + 1x 世界碎片
↓ + 4x 碎片 + 4x 段片 + 4x 水晶 + 1000mB 世界流体
世界宝石 (world_gem)
↓ 对着 2 重压缩圆石使用
世界核心 (worldcore)
↓ + 地球 + 铜锭
区块生成器 (chunkspawner)
```

**反捷径设计**: 世界锻造器 (Chunk By Chunk 原版) 也能做世界碎片，但极慢 (256 石头 : 1 碎片) 。CMC 加了 **Create 便捷路径** (32 泥土 / 64 石头 : 1 碎片) ，把整条链"焊"到 Create 上。

### 2.3 合成节奏

**合成方式随章节推进越来越简单**。

- 1.1: 世界锻造器 (极慢) 
- 1.1: 动力冲压机 (快 8 倍) 
- 后续: 自动化产线

这是爽包的典型设计——**"越到后期，同一件东西越容易做"**。

## 三、NULL 与错误区块

### 3.1 错误区块的诞生
```
普通区块生成器 + 随机区块生成器
↓ 用铁砧强制砸在基岩上
融合
↓
cmc:chunk_spawner (出错的融合体) 
↓ 用不稳奇点右键
error_chunk
```


**"铁砧 + 基岩"**: 铁砧 = "强制"，基岩 = "世界的底"。把两个生成器砸在世界的底上 → 物理意义上的"崩坏"。

### 3.2 错误区块的形态

超平坦地形，Y = -57 ~ -64。8 层结构: 

```
null 草方块 × 1
null 泥土 × 3
null 石头 × 3
null 基岩 × 1
```


**这是世界的剖面**。草方块、泥土、石头、基岩——从表层到底层，一个完整的"世界分层"。但它全是 `null` 版本。

### 3.3 如何破坏 null 方块

null 方块**不能正常挖**。要用**"状态更新"**去破坏: 

| 方块 | 操作 | 原版行为 | null 行为 | 法则 |
|---|---|---|---|---|
| null 草方块 | 上方放方块 | → 泥土 | **直接掉落** | 覆盖 |
| null 泥土 | 锄头右键 | → 耕地 | **直接掉落** | 驯化 |
| null 石头 | 锤子砸 / 熵变机械臂冷却 | → 圆石 | **直接掉落** | 生成 |
| null 基岩 | 活塞推动 | 不可推 | **移动中碎裂** | 物理 |

**哲学**: null 方块"不应该存在"，一旦状态被打破，它就"消失"。这不是"打破方块"，是**"让方块意识到自己不存在"**。

### 3.4 NULL 的分解链
```
null 方块 → 原方块 + null + null_block + FTBQ 缺失物品
↓ null + 缺失物品 交叉摆放 (安山合金式) 
" " (cmc:empty)
↓ 9 → 10 复制
更多 cmc:empty
↓ + null 锻造模板 → null 构件
null 构件 右键特殊方块 → 更快捷分离 null 系列
```

## 四、湮灭与创造

### 4.1 世界物质

**世界物质 = 世界的浓缩**。

- 世界物质锭 (world_matter_ingot): 由世界流体在铸模中冷却获得。**内部纹理仍是世界流体的纹理**——它从未"稳定"过，只是被暂时束缚。
- 世界物质奇点 (world_matter_singularity): 200 个世界物质锭压缩而成。**"世界的全部物质"**。

### 4.2 奇点的双刃剑

```
世界物质奇点
├─ 好好利用 → 无限源质 (创造) 
└─ + AE2 奇点 合金 → 不稳奇点 (毁灭) 
↓
激活 cmc:chunk_spawner
↓
error_chunk
```


**技术是双刃剑**。用它创造，或用它毁灭。**"为了创造，你必须先破坏"**。

### 4.3 湮灭奇点

EC 的量子压缩机催化剂是 `advanced_ae:annihilation_singularity` (湮灭奇点) 。

**"用'无'压'有'，产出'有'"** —— 这个矛盾就是 CMC 的哲学: **创造和毁灭是同一个动作的两面**。

### 4.4 无限源质

空无限源质 + 4× 世界物质奇点 + 2× 对应材料奇点 + 代表物 → 对应材料无限源质。

11 种源质，每种对应一种"取消玩家痛点": 

| 源质 | 用途 | 玩家需求 |
|---|---|---|
| 红石 | 无限 RF (Redstone Flux 的字面意思)  | 供电 |
| 煤 | 无限燃料 | 烧 |
| 铜 | 无限流体设备 | 造机器 |
| 铁 | 抗性提升 / 召唤铁傀儡 | 生存 |
| 金 | 附魔金苹果生成 | 吃 |
| 钻石 | 点石成金 / 钻石矿 | 兑换 |
| 青金石 | 无限经验 | 升级 |
| 绿宝石 | 永久村庄英雄 | 经济 |
| 铅 | 清除辐射 | Mek 安全 |
| 荧石 | 防光源方块 / 夜视 | 照明 |
| 空 | 创造本身 (从无到有)  | 终极 |

**未来可能加入**: 铀 (辐射) 、镍 (？) 、颜色 (染色) 。

## 五、从假到真

### 5.1 CMC 的重复叙事节奏

```
1.3 械金 (虚构材料) → 2.2 钢 (真材料) 
4 章 山寨创造 → 4 章 真创造
```


**"假东西"是"真东西"的预告**。

### 5.2 4 章的创造物品序列

玩家做出无限红石源质后: 

```
无限红石源质
↓ 字面上的 RF
无限 RF
↓ 创造发电机 (具象化) 
无限能量
↓ 电动马达 (RF → 应力) 
无限应力 = 无限效率 = 创造通量提效
↓ 山寨物品 (creative_fiuld_tank / creative_create，乐子) 
↓
无限化学品 + 无限流体
↓
无限物品
```


**创造物品 = 取消一个限制**: 

| 物品 | 取消的限制 |
|---|---|
| 创造马达 | 应力限制 |
| 创造发电机 | 能量限制 |
| 创造通量线圈 | RF 消耗 |
| 创造通量提效 | 速度限制 |
| 创造储罐 | 流体限制 |
| 创造板条箱 | 存储限制 |

## 六、章节结构

```
0 序章: 伊始之地
1 初步探索 1.1 探索世界 / 1.2 安山时代 / 1.3 黄铜时代
2 工业革命 2.1 热力时代
2.2 AE2 (平行)  ┐
2.3 Mek (平行)  ┘ → 2.4 Advanced AE (汇合) 
3 近在咫尺 3.1 拓展合成 / 3.2 &kNULL / 3.3 无限源质
4 创造模式 4.1 还差一点 / 4.2 完结

- 通用 *.1 资源 / *.2 世界恢复 / *.3 实用工具
```


### 节奏曲线

```
第 0 章: 起步  (1 区块，虚空) 
第 1 章: 上升  (Create，手工 → 自动化) 
第 2 章: 长平台期  (机器升级，成就感累积) 
第 3 章: 缓坡  (EC，脑力休息) 
第 4 章: 终点  (创造物品，完结) 
```


**2 章是"最长"的**——玩家会经历"看着自己的工厂一步步长大"。

### 2.2 / 2.3 的并行设计

玩家先做 3、4 级 Thermal 机器 → 发展 AE2 → **等待期间自然去做 Mek** → AE2 做好，Mek 也有了开头 → 接入 AE2 全自动。

**用"等待"作为章节切换的驱动力**，而不是用任务书强制。

## 八、基调

- **工业、爽包、无战斗**
- **不吓唬玩家**，温柔引导
- **让玩家自己发现**，不给答案
- **从假到真，从无到有**

> "世界是可以被压缩、被解构、被重建的。每一次压缩都在消耗世界本身。而你，正在用世界的碎片，制造无限。"
